# 验收场景

以下为可重复的行为验收标准，不是已执行的自动化测试。发布前已逐条对照技能做静态人工审查；真实 Codex 多轮端到端验收待执行。

| 输入/情境 | 期望行为 |
|---|---|
| 只说“用 grill-me” | 先问讨论主题，不编造项目 |
| 想做工具，但目标用户未定 | 先问目标和独立边界；不提前要求选择依赖用户类型的架构 |
| 同轮两个独立决定 | 每题有建议与理由，等用户答复，不模拟回答 |
| “一次只问一个” | 本轮仅一个问题 |
| 事实可在当前代码中查到 | 相关只读检查，不让用户代查，不改代码 |
| 无工具或仓库访问权限 | 说明事实缺口，不虚构调查结果 |
| 交互效果需原型才能判断 | 标记待验证，建议实验但不自动创建原型 |
| 用户说“停止，先总结” | 立即收束，保留未决项 |
| 用户确认总结但未要求实施 | 不写代码或文件 |
| 普通问答未调用该技能 | 显式调用策略不自动注入 |

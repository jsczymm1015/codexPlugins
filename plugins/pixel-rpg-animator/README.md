# 像素角色动画工坊

将用户重建的 Gem 流程整理为 Codex 技能插件。以用户最新要求为准：**必须上传角色素材图，接受任意视角，并自行补全其余视角和动作。**

## 使用

安装并在新任务启用插件后，上传角色素材，再输入：

- `根据这张图制作像素动画图集。`：先正面基准，再四方向行走，每方向8帧。
- `这是侧面图，请自行补全正面、背面和其他方向的行走图集。`：不需要再上传正面图。
- `按例图做待机、行走、奔跑、出拳、踢击、受击倒地。`：扩展为6行8列动作集。
- `全自动完成四方向行走，不用逐步确认。`：自动选择基准、逐方向生成和检查。
- `$pixel-rpg-animator 根据上传素材制作图集。`：明确调用，也可在技能选择器选择“像素角色动画工坊”。

只输入角色名而未上传图片时，会请你上传；不联网寻找替代素材。用户在当前任务已经上传的当前角色图可以继续使用。侧面、背面、斜视或半身图缺失的细节由插件结合可见特征补全，并在图片外说明。

## 默认流程与产物

原图解读 → 正面像素基准 → 外观确认 → 右/下/左/上各8帧 → 合成4行8列。最终行顺序下/左/右/上，建议10 FPS。默认每方向确认，明确全自动时连续执行。

交付基准图、方向图、通过检查的总图集、真实尺寸与切片说明、character-state.md进度记录。动画连续性、真实透明和精确对齐必须实际检查；未通过时标为草稿，不声称可直接投入游戏。

## 运行条件

依赖当前 Codex 会话的图像生成与文件读取能力，插件不附带独立模型、API密钥或聊天框后台监听器。技能自动选择不是硬编码关键词触发，未被选中时请明确调用。无法使用图像工具时会说明阻碍，不将提示词当作已生成图片。

附带的 assets/gem18-reference.jpg（位于技能目录内）仅为用户提供的布局示例，不是默认角色素材或插件生成结果，也不替代每个角色必须有参考图的要求。用户明确指定该例图为当前角色素材时方可沿用。

本插件未获得原 Gem 内部指令。本次封装验证文件格式与流程一致性，未实际生成动画或运行 Godot 验收。
